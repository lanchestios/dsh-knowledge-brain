# excalidraw 图位

架构图、关系图（含 ER）是自由画布。简单图（几张盒几条线）由写页面的人在编辑态画；**带边账的复杂关系图（域框＋对象盒＋跨域边，15 条边上下）不由人画、也不靠手推坐标——图是「生成器＋校验器」迭代出来的**，按文末一节走。三步放图位：

1. 建空场景文件 `asset/diagrams/<日期>/<名>.excalidraw`，内容一字不差写最小骨架（纸底 #ffffff，暖纸皮）：

   ```json
   {"type":"excalidraw","version":2,"source":"dsh-knowledge-brain","elements":[],"appState":{"viewBackgroundColor":"#ffffff"}}
   ```

2. 正文嵌引用，单行独立成段：`![](asset/diagrams/<日期>/<名>.excalidraw)`——列表、引用块里不识别。默认等比压满正文栏宽、高度随画布比例自适应、超高自动封顶（75vh、封顶后等比居中）——不写高度参数（`?h=` 是 html 嵌入件的东西，excalidraw 一律自动高度）。
3. 阅读态显示静态图（空场景显示「未画」占位）；简单图在编辑态点图开全屏画布画、保存写回文件，图位引用不动。

存量 mermaid 架构图与 html 关系图照旧渲染，不迁移。

**画布风格（暖纸皮）**，架构图、关系图、ER、机制示意都按这一套，不特指哪类图。开画布画的人照 token 表：

| 用途 | 值 |
|---|---|
| 纸底 | 暖白 `#ffffff`，分界线一律暖调 `#e5e1d8` |
| 分组框 | 一图有几组并列（子系统、域、模块、泳道都算组）时每组挑一族低饱和族色（蓝灰 `#9ab0c4`、砂 `#d9c08a`、青草 `#9dbd8a` 这类，组多再添族）：组框铺族色淡底（比描边淡两层）+ 同族描边 1px、组题深蓝 `#2d5a9e` |
| 对象盒 | 白底 + 所在组族色描边 1.1px、圆角——白盒落在组淡底上，盒与组两级可辨 |
| 外部 / 被引用对象 | 淡褐 `#f1efe9` 底 + `#b0a894` 虚线 |
| 组内关系 | 暖灰 `#8a8578` 实线 1.1px |
| 跨组引用 | 灰褐 `#b0a894` 虚线 1.2px |
| 关键边 | 全图少数要突出的边用琥珀 `#c8871e` 1.5px，标签 `#8a5f10`——多数边保持灰系，琥珀才有焦点作用 |
| 文字 | 主文暖黑 `#2b2a26`、副文深褐 `#4f4839`——svg 默认压栏宽会整体缩小一半，字号必须放大写：副题与边标 ≥13.5px、对象名 ≥19px，宁大勿小 |
| 走线 | 横平竖直：箭头走肘线（直角折线）贴框进出，不画斜线直连 |
| 箭头 | 小实心三角：线宽 1 头就小，别用粗线大头 |

## 复杂图：生成器＋校验器

带边账的平台视角关系图（域框＋对象盒＋跨域边账）走这条路。实战结论：手推走线 25 条边错 8 条，手推只用来定「拓扑可行性」，落盘必须由程序生成；**先写校验器再写生成器**——校验器是需求的可执行版本，没有它讨论「够不够严格」没有依据。

**工作流**：读页面提取边账（编号/源/目标/边义/边类）到生成器的 LEDGER 常量 → 定域框分区（列×行）与每盒归属 → 手推边的拓扑（只判走得通，不写精确坐标）→ 写 gen.py（常量＋几何工具＋元素模板＋自动摆号摆标＋落盘）→ 写 check.py（全部规则写成断言）→ 循环逐条修到全绿 → 落最终文件，progress.md 记迭代轮次与白名单。

**生成器硬约束**：

| 项 | 约束 |
|---|---|
| 元素键集 | 三种类型各一套**精确**键集，多一少一都出问题：文本＝base＋text 族；矩形＝base＋`roundness:{"type":3}`；箭头＝base＋points 族且 `roundness:null` |
| base 固定值 | `version=1`、`updated=1`（易误写成 0）、`angle=0`、`opacity=100`、`roughness=0`、`isDeleted=false`、`boundElements=null`、`groupIds=[]`、`frameId=null`、`link=null`、`locked=false` |
| 箭头 | `points[0]=[0,0]`；相邻点正交（x 相等或 y 相等）；`width/height`＝点集包围盒；`endArrowhead:"triangle"`、`startArrowhead:null`、不建绑定 |
| 文本宽高 | 全角 1、ASCII 0.55：`w=round(fs×(全角数+0.55×半角数), 1)`、`h=fs×1.25` |
| seed / versionNonce | 两个递增计数器，全局唯一且互不相交 |

**摆号摆标必须自动。** 边多时圈号＋边标手摆几乎不可能一次摆对：生成器里用采样候选点＋多轮回填（难放的号优先排），forbidden 列表要含所有对象盒的内缩区——边标签落进盒内会被当成副题，副题数就错了。

**校验器必检**（按优先级）：

1. **语义对账**：边的编号、源、目标、边义、边类与页面边账表**逐行一致**（正则解析 Markdown 表比常量更可靠）；图内标签允许用边义的可匹配前缀，`want.startswith(label) or label.startswith(want)`。
2. **拓扑**：端点贴盒边框 ±2（从盒几何算，`x+w`，不写死字面量）；不穿盒（盒内缩 2.5、线段两端内缩 2 避免端点误判）；不压字（文字外扩 2）；不穿图例框。
3. **token 一致**：边类→线型（色/宽/虚实）在线、图例样本、标签色三处一致；自身域盒＝白底＋域色实线，引用域盒＝`#f1efe9`＋虚线；每盒恰一条 13.5px 副题。
4. **圈号贴邻**：横段号在线上或下方 40px、竖段号在线左或右侧 32px，且投影区间重叠；按距离排序，最近的边必须是自己的、次近要比最近远 ≥4（否则歧义）。标签贴号四方位（右/左/下/上）均可，色随边类。
5. **版面**：画布四边留白 ≥40（按 points 绝对坐标算，不是 x/y）；矩形除包含关系外不交叠；文本两两不交叠。

**交叉白名单。** 两条边端口交错——A 的起点在 B 的起点外侧、而终点在 B 的终点内侧——交叉无法通过改走线消除：能换端口就换，换不了就接受交叉、白名单放行并附原因，别为零交叉把边绕成六段折线。校验器里维护 `ok_pair` 集合，命中才豁免。

**坑表**（实战踩过，解法直接抄）：

| 坑 | 解法 |
|---|---|
| 手推走线漏检（25 条边错 8 条） | 一律交校验器；手推只定拓扑 |
| 端口坐标写死（盒右缘是 `x+w`，写死字面量换盒就错） | 端点从盒几何算 |
| 边标签落进盒内，被当成副题、副题数变多 | 摆放器 forbidden 列表含所有对象盒的内缩区 |
| 摆放顺序固定导致死锁（后放的号被先放的占了唯一活口） | 多轮回填＋难放的号优先 |
| 采样点不够（唯一活口在两个采样点之间） | 横向采样覆盖 `lo+8 / 中 / hi-100 / hi-30 / lo-6 / hi-26` |
| 一条边的竖线把旁边边的候选口袋全封了 | 候选点按「自身线距」排序时留 28px 档 |
| 画布溢出（箭头 `x/y` 是包围盒左上角，不是起点） | 边距检查按 `points` 绝对坐标算 |

**几何判定函数**（Python，直接抄进校验器）：

```python
def segs(a):  # 箭头 → 绝对坐标线段列表
    pts = [(a["x"]+p[0], a["y"]+p[1]) for p in a["points"]]
    return [(pts[i], pts[i+1]) for i in range(len(pts)-1)]

def seg_box(seg, box):  # 线段穿盒（段端各内缩 2、盒内缩 2.5，避免端点贴框误判）
    (x1, y1), (x2, y2) = seg
    rx1, ry1 = box["x"]+2.5, box["y"]+2.5
    rx2, ry2 = box["x"]+box["width"]-2.5, box["y"]+box["height"]-2.5
    x1, x2 = sorted((x1, x2)); y1, y2 = sorted((y1, y2))
    if x1 != x2: x1, x2 = x1+2, x2-2
    if y1 != y2: y1, y2 = y1+2, y2-2
    return x1 < rx2 and rx1 < x2 and y1 < ry2 and ry1 < y2

def cross(s1, s2):  # 正交线段相交（含共线重叠）
    p1, q1 = s1; p2, q2 = s2
    if p1[1] == q1[1] and p2[1] == q2[1]:          # 双横
        if p1[1] != p2[1]: return False
        l1, u1 = sorted((p1[0], q1[0])); l2, u2 = sorted((p2[0], q2[0]))
        return l1 <= u2 and l2 <= u1
    if p1[0] == q1[0] and p2[0] == q2[0]:          # 双竖
        if p1[0] != p2[0]: return False
        l1, u1 = sorted((p1[1], q1[1])); l2, u2 = sorted((p2[1], q2[1]))
        return l1 <= u2 and l2 <= u1
    if p1[1] == q1[1] and p2[0] == q2[0]:          # 横×竖
        l1, u1 = sorted((p1[0], q1[0])); l2, u2 = sorted((p2[1], q2[1]))
        return l1 <= p2[0] <= u1 and l2 <= p1[1] <= u2
    if p1[0] == q1[0] and p2[1] == q2[1]: return cross(s2, s1)  # 竖×横
    return False
```

**终检清单**：LEDGER 与页面边账逐行一致；对象名与盒一一对应；域框标题齐全；圈号＋边标全部就位；每盒恰一条副题；图例＝1 框 3 箭 5 文案；无穿盒、压字、交叠、边距越界；交叉＝白名单集合（每条有原因）；`check.py` 输出 ALL CHECKS PASSED；progress.md 记元素数、迭代轮数、白名单与发现的真错。
