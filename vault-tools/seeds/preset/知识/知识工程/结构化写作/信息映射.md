Information Mapping，Robert E. Horn 1967 年提出的结构化写作方法。一句话：**把文档拆成一个个只讲一件事、贴着标签的「信息块」，并按这块信息属于哪种类型来决定它长什么样**——步骤用编号，结构用树和表，事实用表。

它是[[结构化写作]]这一脉的源头，后来的 DITA、EPPO 都建在它的类型学上。

## 出身

Horn 是哈佛与哥伦比亚的研究者。1969 年 8 月他与 Elizabeth H. Nicol、Joel C. Kleinman 发表《Information Mapping for Learning and Reference》，方法本身可追溯到 1967 年。

出发点是**视觉呈现影响可及性、理解与绩效**。做法是实证的：收集数十种常见文档类型，拆解成结构组件，识别出 **200 多种信息块类型**，再归并成少数几种信息类型。

## 核心构件

三层嵌套，从小到大：

| 层 | 是什么 | 规则 |
|---|---|---|
| **Block**（信息块） | 一个主旨。可以是句子、列表、表格、图或多媒体 | 每块只讲一件事、贴 3–5 词标签、与相邻块视觉分隔（如一条横线）。**它取代的是「模糊的段落」** |
| **Map**（信息图） | 若干块组成的模块化单元 | 一块回答一个「W 问题」（谁 / 哪里 / 为什么 / 是什么），一张图由不同类型的块组成 |
| **Topic / Document**（主题 / 文档） | 图再往上组装 | —— |

## 七种信息类型

类型属于**分析**阶段——先判断这段内容是哪一类，再决定怎么呈现。

| 类型 | 定义 | 典型读者问题 |
|---|---|---|
| Procedure（步骤） | 完成一项任务的一串顺序步骤 | 怎么换轮胎 |
| Process（过程） | 不同角色间的任务安排，说明各阶段发生什么、彼此怎么交互 | 发动机怎么工作 |
| Principle（原则） | 支配行为的前提与规则，不随情境改变 | 什么该做、什么不该做 |
| Concept（概念） | 观念、想法；共享一组关键属性的一类事物。简单定义也算概念 | 安全气囊是什么 |
| Fact（事实） | 一条为真且可观察的信息 | 这个值是多少 |
| Structure（结构） | 可以被分成有边界的部件的东西；说明部件构成与相互作用 | 它由哪几块组成 |
| Classification（分类） | 把同类归到一起、与不同类分开 | 这属于哪一类 |

两个容易踩的点：

- **常见的说法是「六种」而非七种**。Horn 团队与 Information Mapping 公司自己的材料多数省掉 Classification（分类），只讲 procedure / process / principle / concept / fact / structure 六类。
- **类型是相对读者的**。同一样东西对孩子是「概念」，对成人是「事实」——「椅子」就是书里的例子。类型不是内容的固有属性，是内容对**这个读者**的用途。

## 六条组织原则

类型管「这是什么」，这六条管「怎么摆」。两套东西，别混。

| 原则 | 内容 |
|---|---|
| Chunking（分块） | 一切信息切成可管理的单元 |
| Relevance（相关性） | 一块里只放与它主旨相关的东西 |
| Labeling（标签化） | 每块都贴标签，3–5 词 |
| Consistency（一致性） | 同类信息用同样的词、同样的格式 |
| Integrated graphics（整合图形） | 图不是插图，是信息本身 |
| Accessible detail（可及的细节） | 细节要能被找到，而不是被埋掉 |

Labeling（标签化）是回报最高的一条：**标签让读者预先知道要读到什么**，从而进入接收状态，回忆率因此大幅提升。

## 可信边界

- **7±2 的依据被质疑**。Horn 引 George Miller 1955 年的短时记忆研究，推出「句子、段落、小节、章节一律不超过 7±2 块」。批评者指出这是误用：Miller 谈的是同时保持在工作记忆里的项数，而一份文档的小节并不需要被同时记住。有评论尖锐地说，这条原则悖论地假设「读者**没读**的那部分的长度」能影响理解。
- **方法规定结构，不规定外观**。市面上那套横线分栏、左侧贴标签的「Information Mapping 版式」只是一种实现。照着方法写而长得完全不同，同样成立。
- **它是商业方法**。Information Mapping, Inc. 有培训与认证生意，公开材料带推销色彩，实证强度要打折看。
